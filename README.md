# qt-proxy-installer

GitHub installer for the NOFX SOCKS5 proxy package.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/qidoulij006/qt-proxy-installer/main/install-proxy-from-github.sh | \
sudo bash -s -- --username nofx --password 'strong-pass'
```

## Files

- `install-proxy-from-github.sh`: downloads the packaged installer from this repository and runs it
- `dist/nofx-proxy-installer-20260329-152919.tar.gz`: packaged proxy installer bundle
